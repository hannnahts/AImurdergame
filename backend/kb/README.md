# 小A 可知的世界观(知识库写作规则)

这里的文档会被分块、向量化,存进 Chroma,供小A 回答玩家的问题。**小A 只能说它此刻合理知道的事。**

## 内容边界
- 只写:产品功能、房屋布局与设备、论坛背景、**已经显示给玩家看的**记录与事件。
- **永远不写**:玩家与"前任/创造者"的关系、AI 的自由意志与被重置的弧线、事发夜的动机与工单、小雅与小A 的私聊内容,以及任何反转。禁用词见 `forbidden_terms.txt`,`tests/test_kb_boundaries.py` 会自动检查。
- **谜题敏感信息**(密码的组成部分、后台 PIN、管理员权限规则、设备归属)只放在**解开对应谜题之后**的档位,或干脆不写。例如宠物名"布丁"和生日是密码的组成部分,所以只出现在档位 1 以后。

## 档位(unlock_tier,写在每个文档开头的头信息里)
| 档位 | 含义 | 文件 |
|---|---|---|
| 0 | 开局可知 | `00-*`、`01-*` |
| 1 | HomeMind 已登录(解开"她的密码") | `10-*` |
| 2 | 已解开"摆正那一晚" | `20-*` |
| 3 | 第一章四个谜题全部完成 | `30-*` |

## 格式
- 文件开头:`---` / `unlock_tier: N` / `---`(N 为 0 到 3)。
- 正文按 `##` 小节组织,每个小节一个主题,控制在 300 字以内。
- 每个档位至少 5 个小节,全库至少 30 个小节。
